🔒 Privacidad y seguridad

Esta aplicación es una herramienta independiente de apoyo docente. No es una aplicación oficial de la SEP ni de la AEFCM y no sustituye sus sistemas, trámites o procedimientos oficiales.

Datos utilizados

Se utilizan únicamente los datos necesarios para identificar al estudiante y realizar seguimiento escolar: ID, nombre(s) y primer apellido, turno, grupo, número de lista, cumpleaños solo con día y mes, observaciones o incidencias escolares pertinentes y registros académicos generados en la aplicación.

Correo institucional en Vespertino

Cuando sea necesario para el seguimiento escolar de Vespertino, el docente puede registrar el correo institucional del alumno. Este dato se utiliza únicamente dentro de App Docente y no se comparte con Mi Español ni con Seguimiento Familiar.

Dónde se almacenan

Los datos que requieren sincronización se envían a un servicio en línea con controles de acceso. Los portales consultan únicamente la información asociada a la sesión iniciada mediante ID y PIN.

Contenido del dispositivo

La aplicación no solicita acceso a contactos, ubicación, micrófono, fotografías, videos, mensajes personales, contraseñas ni información bancaria. Cuando el docente elige un archivo para importar, restaurar, respaldar o publicar material, se utiliza únicamente el archivo seleccionado expresamente.

Notificaciones

Las notificaciones utilizan exclusivamente los datos técnicos necesarios para registrar y entregar avisos mediante Web Push.

Mensajería

El chat escolar conserva únicamente la conversación correspondiente a la semana escolar en curso. Al iniciar una nueva semana escolar, la conversación anterior se elimina de acuerdo con la política de retención configurada.

Finalidad

La información se utiliza para organización, comunicación y seguimiento escolar. No se utiliza para publicidad ni para fines comerciales.

Ningún sistema puede prometer seguridad absoluta. Se aplican minimización de datos, credenciales y controles técnicos de acceso para reducir riesgos.
