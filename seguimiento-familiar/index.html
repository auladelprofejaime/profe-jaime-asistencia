Privacidad y seguridad

Seguimiento Familiar utiliza únicamente los datos necesarios para identificar al estudiante y mostrar su información escolar.

El acceso se realiza mediante ID del alumno de 5 dígitos y PIN familiar. No se solicita nombre del familiar, teléfono, correo personal ni fecha completa de nacimiento.

Instalar esta aplicación no permite al profesor acceder a contactos, fotografías, videos, ubicación, micrófono, WhatsApp, mensajes personales, contraseñas, archivos personales ni información bancaria.

Las notificaciones utilizan exclusivamente los datos técnicos necesarios para registrar y entregar avisos mediante Web Push.

La información se utiliza para seguimiento y comunicación escolar y no para publicidad ni fines comerciales.

Esta es una herramienta independiente de apoyo docente. No es una aplicación oficial de la SEP ni de la AEFCM y no sustituye sus sistemas, trámites o procedimientos oficiales.
